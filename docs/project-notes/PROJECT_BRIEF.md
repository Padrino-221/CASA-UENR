# ⛪ University Church Management System (U-CHMS)

## Project Brief & Vision

The **University Church Management System (U-CHMS)** is a high-performance, centralized administration platform designed specifically for the **Christ Apostolic Students and Associates** and its campus-based ministries.

The system provides a unified data environment for managing the hierarchy of national, regional, and local church chapters within the university landscape.

---

### 🚀 Core Objectives

1.  **Centralized Governance**: Enable National Administrators to oversee all regions and chapters from a single portal.
2.  **Data-Driven Ministry**: Move from paper-based spiritual records to real-time digital tracking.
3.  **Financial Transparency**: Standardize the recording and reporting of chapter collections and offerings.
4.  **Student Management**: Maintain a comprehensive database of student members across all tertiary campuses.

---

### 🛠 Technical Architecture

The application is built on a modern, future-proof stack optimized for performance and security:

- **Framework**: Next.js 16.2.2 (App Router) utilizing Turbopack.
- **Database**: Prisma ORM with SQLite (Local Development) / PostgreSQL (Production).
- **Security**: Auth.js v5 (NextAuth) with Edge-optimized route protection and Role-Based Access Control (RBAC).
- **Styling**: Vanilla CSS Modules with a custom-engineered Deep Ocean Design System.
- **Icons**: Lucide React for consistent, high-end iconography.

---

### 📦 Key Management Modules

| Module           | Description                                                                           |
| :--------------- | :------------------------------------------------------------------------------------ |
| **Regions**      | Manages the geographical divisions of the ministry (e.g., Greater Accra Region).      |
| **Chapters** | Manages local university chapters (e.g., UG, KNUST, UPSA).                   |
| **Members**      | A deep searchable directory including Student Profiles, Levels, and Personal Details. |
| **Financials**   | Secure recording and tracking of weekly collections and spiritual offerings.          |
| **Calendar**     | Coordination of academic cycles and ministry-wide events.                             |
